Brand New Front End — From Scratch

April 26, 2026 Release UI

We built a brand new front end experience for AcreetionOS from the ground up. The site now ships a modern, responsive interface that better reflects the project's goals: clarity, accessibility, and an inviting experience for new users.

What’s New

  • Redesigned landing pages with clearer calls-to-action and faster load times.
  • Interactive demo that emulates the AcreetionOS desktop experience — try it from mobile or desktop.
  • Built-in AIDEN assistant powered by OpenRouter via our server proxy (no API keys in the browser).
  • Live visitor counter and nicer social links, plus a refreshed docs/wiki layout.
  • Improved accessibility: skip links, focus-visible styles, and reduced-motion preferences respected.

Try The Demo

We Want Your Feedback

This redesign is for the community. If something feels off, or you have ideas (layout, copy, features), please let us know:

  • Open an issue on our GitHub.
  • Join our Discord and drop a screenshot.
  • Use the feedback form on the Contact page.

Mobile Friendly

The site is now fully responsive. Navigation collapses, buttons are finger-friendly, and the demo is usable on small screens. If you spot layout issues on a particular device, tell us the device and browser so we can reproduce it.

Thanks to everyone who contributed design tweaks, testing, and the relentless patience while we rebuilt this. We’ll continue iterating — next up: performance budgets and a subtler onboarding flow for new users.

— The AcreetionOS Team
