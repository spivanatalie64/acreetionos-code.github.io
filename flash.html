Flash to USB

Option 1: Download & Flash Script (Linux/macOS)

Download this script, make it executable, and run it. It will download the ISO and flash it to your USB drive.

#!/bin/bash
# AcreetionOS USB Flasher
# Usage: sudo bash acreetionos-flash.sh  
# Editions: cinnamon, xl, 32bit, hyprland, plasma, xfce, mate, gnome, sway, i3

set -e
EDITION="${1:-cinnamon}"
DEVICE="${2:-/dev/sdX}"

case "$EDITION" in
 cinnamon) URL="https://sourceforge.net/projects/acreetionos-iso-image/files/AcreetionOS-1.0-x86_64.iso/download";;
 xl)    URL="https://iso.acreetionos.org:8448/acreetion/AcreetionOS_XL-1.0-x86_64.iso";;
 32bit)  URL="https://pub-173a1f638a3b4c95b5f58b09c0b968aa.r2.dev/AcreetionOS32-latest.iso";;
 hyprland) URL="https://pub-173a1f638a3b4c95b5f58b09c0b968aa.r2.dev/AcreetionOS-Hyprland-latest.iso";;
 plasma)  URL="https://pub-173a1f638a3b4c95b5f58b09c0b968aa.r2.dev/AcreetionOS-Plasma-latest.iso";;
 xfce)   URL="https://pub-173a1f638a3b4c95b5f58b09c0b968aa.r2.dev/AcreetionOS-XFCE-latest.iso";;
 mate)   URL="https://pub-173a1f638a3b4c95b5f58b09c0b968aa.r2.dev/AcreetionOS-MATE-latest.iso";;
 gnome)  URL="https://pub-173a1f638a3b4c95b5f58b09c0b968aa.r2.dev/AcreetionOS-GNOME-latest.iso";;
 sway)   URL="https://pub-173a1f638a3b4c95b5f58b09c0b968aa.r2.dev/AcreetionOS-Sway-latest.iso";;
 i3)    URL="https://pub-173a1f638a3b4c95b5f58b09c0b968aa.r2.dev/AcreetionOS-i3-latest.iso";;
 *) echo "Unknown edition: $EDITION"; exit 1;;
esac

echo "Downloading $EDITION..."
curl -L -o /tmp/acreetionos.iso "$URL"
echo "Flashing to $DEVICE..."
sudo dd if=/tmp/acreetionos.iso of="$DEVICE" bs=4M status=progress && sync
echo "Done! Safe to remove $DEVICE"

Option 3: Ventoy (All Platforms)

  1. Download Ventoy for your OS
  2. Install Ventoy to your USB drive (this formats it)
  3. Simply copy the ISO file onto the Ventoy partition
  4. Boot from the USB — Ventoy will show a menu of all ISOs

Option 4: Rufus (Windows)

  1. Download Rufus
  2. Select your USB drive
  3. Click SELECT and choose the downloaded ISO
  4. Click START and wait for completion
