AcreetionOS Immutable (formerly ArttulOS) — Immutable Edition

AcreetionOS Immutable is an immutable, container-native spinoff of AcreetionOS. Same Arch base, same Cinnamon desktop — but with a read-only root filesystem, atomic A/B updates, and containerized workloads via Podman. You literally cannot break the base system.

Autobuild Pipeline

Important: These are automated builds provided as a service to the community. Please do not contact Darren with support requests for unofficial editions. Instead, reach out to Natalie (@sprungles) in our Discord for assistance. All unofficial editions are still being worked on and are automatically rebuilt every Monday at 6:00 UTC via GitHub Actions. Manual triggers are limited to one per UTC day. The pipeline:

  • Clones the main AcreetionOS source repository
  • Applies edition-specific patches (desktop environment, packages, configs)
  • Builds a bootable ISO via mkarchiso inside a Docker container
  • Uploads the finished ISO to Cloudflare R2 for free downloads
