System Requirements

AcreetionOS is optimized to run on a wide range of hardware, from older laptops to modern gaming PCs. Check the requirements below to ensure compatibility.

🎯 Minimum Requirements

Processor (CPU)64-bit x86_64 processor
1.5 GHz+
Memory (RAM)2 GB minimum
Storage20 GB free disk space
GraphicsAny GPU with 256MB VRAM
Integrated graphics supported
Display1024×768 (Calamares requires 1024×600 minimum)
Boot ModeUEFI or Legacy BIOS

Note: System will be functional but may feel sluggish with heavy multitasking.

✅ Recommended Requirements

Processor (CPU)Modern 64-bit dual-core
2.0 GHz+
Memory (RAM)4 GB or more
Storage40 GB+ SSD recommended
(NVMe for best performance)
GraphicsDedicated GPU with 512MB+ VRAM
Intel/AMD/NVIDIA supported
Display1920×1080 (Full HD) or higher
NetworkEthernet or Wi-Fi adapter

Best for: Smooth multitasking, development, light gaming, and daily use.

Hardware Compatibility

Processors (CPUs)

✓ Intel Core 2 Duo and newer, Pentium 4+ (64-bit), Celeron, Atom (x86_64 only)

✓ AMD Athlon 64 and newer, Ryzen series, EPYC, Threadripper

⚠ 32-bit AcreetionOS builds 32-bit (i686) images from the Arch Linux 32-bit repositories (archlinux32.org). These images are untested — we do not run QA on them.

▸ 32-bit details
We build 32-bit images, but they are not tested.

We compile 32-bit (i686) ISOs using the upstream Arch Linux 32-bit repositories. We do not maintain our own package repos for 32-bit. These builds are provided as-is for testing, education, and automated deployment pipelines.

⚠ Note: We build these images so they exist, but we may not know everything about how they behave on every system. 32-bit hardware and software combinations vary widely, and our testing capacity is limited. If you run into issues, community knowledge and the Arch32 repos are your best resources.
